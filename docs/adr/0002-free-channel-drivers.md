# ADR-0002：免费通道用登录态驱动，并做成可插拔 driver

- 状态：已采纳（2026-11-12）
- 背景：用户要求「不用收费模型，接入豆包这种免费问答助手」。豆包官方 API（火山方舟）按 token 计费；
  真正零成本的只有网页/客户端的登录态，而它没有公开 API、没有 SLA、有风控。
- 决策：定义统一的 `AssistantDriver` 接口，实现四种通道：
  `WebViewDriver`（手机直驱）、`GatewayDriver`（PC Playwright）、`FreeApiDriver`（如 GLM-4-Flash 免费额度）、
  `OnDeviceDriver`（离线兜底）。路由按健康度打分 + 粘性会话 + 熔断降级。
- 理由：
  1. 单一逆向通道一旦失效，产品整体不可用；接口隔离后换通道不影响上层。
  2. 登录态驱动必须处理验证码/风控/改版，这些是**运行时**问题，只能靠降级与可观测性兜底。
  3. 自用侧载场景下风险可控；不内置他人 Cookie、不随应用分发登录态。
- 代价：需要维护多套 driver 与选择器版本；测试矩阵变大。
- 风险与缓解：账号风控 → 低频、独立小号、保留免费额度兜底；选择器失效 → 版本化 + PC 端热更新。
- 明确不做：把逆向接口包装成对外收费服务（违反站点条款，且放大封禁风险）。
